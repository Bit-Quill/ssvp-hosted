Snowflake Excel Plugin

Connect to Snowflake semantic views and build interactive reports directly in Excel

📥 Download Manifest

Installation Instructions

  1. Click the download button above to save the manifest file
  2. Open Microsoft Excel (Desktop version)
  3. Go to Insert → Get Add-ins (or My Add-ins)
  4. Click Upload My Add-in
  5. Browse and select the downloaded manifest file
  6. Click Upload
  7. The Snowflake button will appear in your Excel ribbon
Note: This add-in requires Microsoft Excel Desktop. Excel Online has limitations for custom add-in installation.
