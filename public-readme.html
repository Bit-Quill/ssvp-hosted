❄️ Snowflake Excel Plugin

Connect to Snowflake Semantic Views directly from Microsoft Excel

✅ Plugin Status: Active and ready to use!

📥 Installation

Windows

  1. Open Microsoft Excel
  2. Go to Insert tab
  3. Click Get Add-ins or My Add-ins
  4. Select Upload My Add-in
  5. Copy and paste this URL:
https://bit-quill.github.io/ssvp-hosted/manifest.xml

Mac

  1. Open Microsoft Excel
  2. Go to Insert > Office Add-ins
  3. Click Upload My Add-in
  4. Paste the URL above

🔐 Snowflake Setup (One-time)

Before using the plugin, create an OAuth integration in Snowflake:

CREATE SECURITY INTEGRATION my_excel_oauth TYPE = OAUTH ENABLED = TRUE OAUTH_CLIENT = PUBLIC OAUTH_REDIRECT_URI = 'https://bit-quill.github.io/ssvp-hosted/auth/callback' OAUTH_ISSUE_REFRESH_TOKENS = TRUE OAUTH_REFRESH_TOKEN_VALIDITY = 7776000;

Then get your Client ID:

DESCRIBE SECURITY INTEGRATION my_excel_oauth;

Copy the OAUTH_CLIENT_ID value - you'll need it to connect!

🚀 Usage

  1. In Excel, click the Snowflake button in the Home tab
  2. Enter your Snowflake account identifier
  3. Enter your OAuth Client ID (from Snowflake setup)
  4. Click Connect with OAuth
  5. Authenticate in the Snowflake window
  6. Select your Role and Warehouse
  7. Start building reports!
💡 Tip: Installing via URL means you'll automatically get updates when we release new features!
